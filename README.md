# Clasificación de Sentimiento en Reviews de E-commerce
## Problema de negocio

Las plataformas de e-commerce reciben miles de reseñas de usuarios diariamente, lo que dificulta su análisis manual.

Este proyecto tiene como objetivo desarrollar un modelo de procesamiento de lenguaje natural (NLP) capaz de clasificar automáticamente las reseñas en positivas o negativas, permitiendo:

- Detectar experiencias negativas de clientes

- Mejorar la toma de decisiones sobre productos

- Optimizar la gestión de la experiencia del usuario

## Objetivo

Construir un pipeline completo de NLP que incluya:

- Análisis exploratorio de datos (EDA)

- Preprocesamiento de texto

- Representación numérica con TF-IDF

- Modelado con redes neuronales en PyTorch
